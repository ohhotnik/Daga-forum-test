Найди 3 светящиеся звезды и выберись из дома.

ЛАПОЧКА

Она просто хочет поиграть…

ЗАДАНИЕ
Найди в тёмном доме 3 светящиеся звезды. Затем доберись до красной двери. Игроки с одинаковым кодом комнаты видят друг друга.

УПРАВЛЕНИЕ
Компьютер: WASD — ходить, мышь — смотреть, F — фонарик, Esc — пауза.
Телефон: кнопки движения внизу, проводи пальцем по экрану, чтобы осматриваться.
Введи одинаковый код комнаты, чтобы встретиться с друзьями.
Подключение требует включённой анонимной авторизации Firebase.
